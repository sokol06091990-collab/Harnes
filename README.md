# Конвертер валют «Курс»

Веб-приложение на русском языке: 10 валют, обмен местами, автоматический пересчёт и ручной курс при отсутствии сети. Адаптировано для телефона.

## Запуск

Нужен Node.js 24 или новее. Внешних зависимостей нет.

```bash
npm start
```

Сервер слушает порт 3000; другой порт можно задать переменной PORT. Проверки: `npm test`.

Курсы загружаются браузером с https://open.er-api.com/v6/latest/USD (ExchangeRate-API). Нужен доступ к этому домену. Источник обновляется раз в сутки; дата отображается рядом с результатом. Это справочные курсы, комиссии и банковские надбавки не учтены. При ошибке приложение сообщает о ней и позволяет ввести курс вручную; вымышленные курсы не подставляются.
